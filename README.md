# Learning — RiSE Lab

Interactive learning modules from the [RiSE Lab](https://milillo.cive.uh.edu) at the University of Houston, built for **CIVE 6359 — SAR Remote Sensing**.

Live site: **https://milillo-lab.github.io/learning/**

## Modules

### SAR Geometry — `sar-geometry/`
Four interactive exercises on SAR acquisition geometry:

| Exercise | Type | Data |
|---|---|---|
| **Look Angle** | draw flight direction / LOS / layover on real scenes | Umbra X-band spotlight (11 scenes) |
| **Where the Summit Lands** | click topography → ellipsoid-geocoding displacement | Umbra + Copernicus GLO-30 + Esri (19 acquisitions) |
| **Look Angle, Swath & Resolution** | parametric widget | — |
| **PRF & the Ambiguity Window** | parametric widget | — |

The two scene exercises read pixel heights from the imagery, so they must be **served over HTTP** (GitHub Pages and WordPress both do this). To run locally:

```bash
cd learning && python3 -m http.server 8000
# open http://localhost:8000/sar-geometry/
```
